# PaddleOCR.js

Official browser OCR SDK and demo for PaddleOCR.

## Workspace

- `packages/paddleocr-js`: browser SDK
- `apps/ppocr_demo`: Vite demo app built on top of the SDK

## Quick Start

```bash
npm install
npm run dev:ppocr
```

Useful commands:

```bash
npm run build
npm run test
npm run check
```
