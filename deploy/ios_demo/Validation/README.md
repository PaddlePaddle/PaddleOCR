# Validation: iOS Pipeline vs Python Reference

Validates that the iOS OCR pipeline produces numerically exact results
matching the PaddleX Python reference.

## Prerequisites

- Python 3.8+
- `paddleocr >= 3.4.0` (`pip install paddleocr`)
- Test images in `test_images/` directory

## Usage

### Step 1: Add test images

Place test images (JPG, PNG) in `test_images/`.

### Step 2: Generate reference output

```bash
python3 generate_reference.py
```

Outputs reference JSON files to `reference/`.

### Step 3: Run iOS pipeline

Run the iOS app on the same test images and export results as JSON to
`ios_output/`.  Each file should match the reference filename (e.g.,
`test_001.json` for `test_001.jpg`).

The iOS app provides a "Validation Export" feature that writes JSON files
in the expected schema.

### Step 4: Validate

```bash
python3 validate.py
python3 validate.py --verbose   # show PASS results too
```

Exit codes:
- **0** -- all images match
- **1** -- at least one mismatch found
- **2** -- missing files or other error

## JSON Schema

Both reference and iOS output files follow this schema:

```json
{
  "image": "filename.jpg",
  "box_count": 5,
  "boxes": [
    {
      "polygon": [[x1, y1], [x2, y2], [x3, y3], [x4, y4]],
      "text": "recognized text",
      "confidence": 0.9876
    }
  ]
}
```

## Match Criteria

| Field        | Comparison          | Notes                                    |
|--------------|---------------------|------------------------------------------|
| Polygons     | Exact integer match | Every coordinate must be identical        |
| Text         | Exact string match  | Character-by-character comparison          |
| Confidence   | Tolerance of 0.0001 | Accounts for ARM vs x86 float differences |
| Box count    | Exact match         | Must have same number of boxes             |
| Box order    | Array order         | Both must use reading order (top-to-bottom, left-to-right) |

```
Validation/

```
