# Inference and Deployment Overview

This section summarizes PaddleOCR 3.x inference, deployment, and delivery options so you can choose the right path for your scenario.

- **Local Inference**: Run PaddleOCR in a local process or server environment, including high-performance inference, inference engine configuration, parallel pipeline inference, and C++ local deployment.
- **Serving**: Expose capabilities as network services, including self-hosted serving and the PaddleOCR official API.
- **Cross-Platform Deployment**: Deploy to on-device and browser environments.
- **Other**: Model export, project packaging, and benchmark guides.
