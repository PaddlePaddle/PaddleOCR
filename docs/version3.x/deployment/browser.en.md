# Browser Deployment

PaddleOCR provides an in-browser inference SDK, PaddleOCR.js. Developers can embed OCR functionality into the browser to enable offline inference. For details, please refer to [PaddleOCR.js](https://github.com/PaddlePaddle/PaddleOCR/blob/main/paddleocr-js).
