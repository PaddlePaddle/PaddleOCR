```swift
struct BoxSorter {
    /// Y-coordinate threshold for same-line detection. Boxes whose top-left y
    /// coordinates differ by less than this value are considered on the same line
    /// and sorted left-to-right. Matches PaddleX hardcoded value of 10.
    static let yThreshold: Int32 = 10

    /// Sort detection boxes in reading order: top-to-bottom, then left-to-right
    /// within the same line (defined by yThreshold).
    ///
    /// Ported from PaddleX `SortQuadBoxes.__call__()` in
    /// `paddlex/inference/pipelines/components/common/sort_boxes.py`.
    ///
    /// Algorithm:
    /// 1. Sort all boxes by top-left corner: first by y, then by x.
    /// 2. Insertion-sort pass: for each box, walk backward and swap with the
    ///    previous box if they are on the same line (y-difference < 10) and
    ///    the current box's x is smaller.
    ///
    /// - Parameter boxes: Unordered detection boxes from DBPostProcessor.
    /// - Returns: Boxes sorted in reading order.
    static func sortInReadingOrder(_ boxes: [DetectionBox]) -> [DetectionBox] {
        guard boxes.count > 1 else { return boxes }

        // Step 1: Sort by top-left point -- first by y, then by x
        // Matches Python: sorted(dt_boxes, key=lambda x: (x[0][1], x[0][0]))
        var sorted = boxes.sorted { a, b in
            let ay = a.points[0][1], ax = a.points[0][0]
            let by = b.points[0][1], bx = b.points[0][0]
            if ay != by { return ay < by }
            return ax < bx
        }

        // Step 2: Backward insertion sort for same-line boxes
        // Matches Python's inner loop: for i in range(num_boxes - 1): for j in range(i, -1, -1): ...
        for i in 0..<(sorted.count - 1) {
            var j = i
            while j >= 0 {
                let nextY = sorted[j + 1].points[0][1]
                let currY = sorted[j].points[0][1]
                let nextX = sorted[j + 1].points[0][0]
                let currX = sorted[j].points[0][0]
                if abs(nextY - currY) < yThreshold && nextX < currX {
                    sorted.swapAt(j, j + 1)
                    j -= 1
                } else {
                    break
                }
            }
        }

        return sorted
    }
}
```

Key details to preserve exactly:
- `yThreshold` is 10 (Int32), matching the Python hardcoded value
- Uses `points[0]` (top-left corner) for both y and x comparisons
- The comparison is `abs(nextY - currY) < yThreshold` (strictly less than, not less-or-equal)
- The backward loop starts at `j = i` and walks to `j = 0`, matching `range(i, -1, -1)`
- The swap is unconditional when both conditions are true: same line AND next.x < curr.x

The implementation consists of three parts:

**Part A: Perspective Transform Matrix (DLT -- Direct Linear Transform)**

Given 4 source points `(x_i, y_i)` and 4 destination points `(u_i, v_i)`, solve for the 3x3 homography H such that for each point pair: `w*[u, v, 1]^T = H * [x, y, 1]^T`.

This produces 8 equations (h[8] = 1.0 by normalization):
```
For each point pair i:
  x_i * h0 + y_i * h1 + h2 - x_i * u_i * h6 - y_i * u_i * h7 = u_i
  x_i * h3 + y_i * h4 + h5 - x_i * v_i * h6 - y_i * v_i * h7 = v_i
```

Solve the 8x8 linear system using Gaussian elimination with partial pivoting.

**Part B: Backward Mapping with Bilinear Interpolation**

For each output pixel (u, v):
1. Compute the homogeneous source coordinate: `[x', y', w'] = H_inv * [u, v, 1]`
2. Normalize: `x = x'/w'`, `y = y'/w'`
3. Clamp x to [0, srcWidth-1], y to [0, srcHeight-1] (BORDER_REPLICATE)
4. Bilinear interpolate from the 4 nearest source pixels
5. Write the RGB value to the output pixel

Use Float64 for the perspective matrix computation (matching OpenCV's getPerspectiveTransform which returns float64), but Float for pixel coordinates during the sampling loop (matching OpenCV's warpPerspective internal behavior).

**Part C: Tall-Narrow Rotation**

After warping, check `if height / width >= 1.5`. If true, rotate the output image 90 degrees counter-clockwise (matching `np.rot90(img)` which rotates CCW). Implement via CGContext with a rotated coordinate transform.

Full structure:

```swift
import CoreGraphics
import Foundation

enum PerspectiveCropError: LocalizedError {
    case invalidPolygon(String)
    case zeroDimension
    case imageCreationFailed

    var errorDescription: String? {
        switch self {
        case .invalidPolygon(let detail): return "Invalid polygon for perspective crop: \(detail)"
        case .zeroDimension: return "Computed crop dimension is zero"
        case .imageCreationFailed: return "Failed to create output CGImage"
        }
    }
}

struct PerspectiveCrop {
    /// Crop a text region from the source image using perspective transform,
    /// then rotate 90 degrees CCW if the result is tall-narrow (height/width >= 1.5).
    ///
    /// Ported from PaddleX `CropByPolys.get_rotate_crop_image()`.
    ///
    /// - Parameters:
    ///   - image: Source CGImage to crop from.
    ///   - polygon: 4 corner points as [[Int32]] in order: TL, TR, BR, BL.
    /// - Returns: Cropped (and potentially rotated) CGImage.
    static func crop(_ image: CGImage, polygon: [[Int32]]) throws -> CGImage {
        guard polygon.count == 4, polygon.allSatisfy({ $0.count == 2 }) else {
            throw PerspectiveCropError.invalidPolygon("Expected 4 points with 2 coordinates each, got \(polygon.count) points")
        }

        let srcPts = polygon.map { (Float($0[0]), Float($0[1])) }

        // Compute output dimensions from polygon edge lengths
        // Matches Python: int(max(norm(p0-p1), norm(p2-p3))) for width
        //                  int(max(norm(p0-p3), norm(p1-p2))) for height
        let cropWidth = Int(max(
            distance(srcPts[0], srcPts[1]),
            distance(srcPts[2], srcPts[3])
        ))
        let cropHeight = Int(max(
            distance(srcPts[0], srcPts[3]),
            distance(srcPts[1], srcPts[2])
        ))

        guard cropWidth > 0 && cropHeight > 0 else {
            throw PerspectiveCropError.zeroDimension
        }

        // Destination rectangle corners
        let dstPts: [(Float, Float)] = [
            (0, 0),
            (Float(cropWidth), 0),
            (Float(cropWidth), Float(cropHeight)),
            (0, Float(cropHeight))
        ]

        // Compute perspective transform matrix (src -> dst)
        let H = try computePerspectiveMatrix(src: srcPts, dst: dstPts)

        // Invert H to get backward mapping (dst -> src)
        let Hinv = try invertMatrix3x3(H)

        // Extract source pixel data as RGB bytes
        let srcPixels = extractRGBPixels(from: image)
        let srcW = image.width
        let srcH = image.height

        // Warp: for each output pixel, sample from source using bilinear interpolation
        var outputPixels = [UInt8](repeating: 0, count: cropWidth * cropHeight * 3)
        for v in 0..<cropHeight {
            for u in 0..<cropWidth {
                // Backward map: (u, v) in dst -> (x, y) in src
                let uf = Float(u) + 0.5  // pixel center
                let vf = Float(v) + 0.5
                let w = Hinv[6] * uf + Hinv[7] * vf + Hinv[8]
                let x = (Hinv[0] * uf + Hinv[1] * vf + Hinv[2]) / w
                let y = (Hinv[3] * uf + Hinv[4] * vf + Hinv[5]) / w

                // Bilinear interpolation with BORDER_REPLICATE (clamp)
                let (r, g, b) = bilinearSample(srcPixels, width: srcW, height: srcH, x: x - 0.5, y: y - 0.5)
                let idx = (v * cropWidth + u) * 3
                outputPixels[idx] = r
                outputPixels[idx + 1] = g
                outputPixels[idx + 2] = b
            }
        }

        // Create CGImage from output pixels
        var cropImage = try createCGImage(from: outputPixels, width: cropWidth, height: cropHeight)

        // Rotate 90 degrees CCW if tall-narrow (matching np.rot90)
        if Float(cropHeight) / Float(cropWidth) >= 1.5 {
            cropImage = try rotateCCW90(cropImage)
        }

        return cropImage
    }
}
```

**IMPORTANT implementation notes:**

1. `distance()` helper: Euclidean distance `sqrt((x2-x1)^2 + (y2-y1)^2)` matching `np.linalg.norm`.

2. `computePerspectiveMatrix(src:dst:)`: Build the 8x8 coefficient matrix A and 8x1 vector b from the 4 point pairs, solve Ax=b using Gaussian elimination with partial pivoting. Return the 9-element array [h0..h7, 1.0]. Use Float64 throughout.

3. `invertMatrix3x3()`: Analytical 3x3 matrix inversion using cofactor/adjugate formula. Use Float64.

4. `extractRGBPixels(from:)`: Draw the CGImage into an RGB CGContext (no alpha) and extract the raw bytes. Use `CGColorSpace(name: CGColorSpace.sRGB)!` and `CGBitmapInfo.byteOrder32Big` with no alpha.

5. `bilinearSample()`: Clamp coordinates to [0, width-1] and [0, height-1] before sampling (BORDER_REPLICATE). Interpolate each channel (R, G, B) independently. Return `(UInt8, UInt8, UInt8)`.

6. `createCGImage(from:width:height:)`: Create a CGImage from raw RGB byte array using `CGContext` and `makeImage()`.

7. `rotateCCW90()`: Create a CGContext with swapped width/height, apply `translateBy(x: 0, y: rotatedWidth)` then `rotate(by: -.pi/2)`, draw the image, and extract. This matches `np.rot90` (counter-clockwise 90 degrees).

8. For the pixel center convention: OpenCV's `warpPerspective` maps integer coordinates to pixel centers. The backward mapping should use `(u + 0.5, v + 0.5)` as the destination coordinate, and subtract 0.5 from the source coordinate before bilinear sampling. This is the standard convention. If validation shows off-by-half-pixel issues, this can be adjusted.
